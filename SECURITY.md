# Security policy

Please do not publish real LDAP credentials, cookies, authentication tokens, or unredacted network captures in issues or pull requests.

For security-sensitive reports, contact the repository maintainers privately through the security reporting options enabled on the GitHub repository. Until a private reporting contact is configured, avoid posting secrets or exploitable details publicly.

This project stores passwords through the operating system keyring and does not persist HTTP cookies. The app is an early alpha; validate portal behavior before enabling unattended login.
